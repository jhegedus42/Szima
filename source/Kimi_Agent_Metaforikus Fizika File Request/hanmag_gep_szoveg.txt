# és a gépállapot veszteség nélkül visszaírható ilyen szöveggé
# (oda-vissza kerekítés).
#
# Formátum:
#   TENY <azonosito> | bit=<nyers bithossz> | <magyar leírás>
#   MODUL <név> | koltseg=<bit> | <tény>:<maradék_bit> ...
#   (a MODUL sor végén üres is lehet a fedéslista)
#
# A maradék bit = amennyi bit a tény leírása a modul
# ISMERETÉBEN még igényel (0 = a modul teljesen levezeti).
# Modul költség = HanMag-tokenek x 9 bit + 32 bit számrész.
# ============================================================
